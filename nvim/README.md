# `config.nvim`

## Installation

First, clone this repository into a suitable location as follows:

For Windows:
```command
$ git clone git@github.com:ubnt-intrepid/config.nvim $env:LOCALAPPDATA/nvim
```

For Unix environment:
```shell-session
$ git clone git@github.com:ubnt-intrepid/config.nvim ~/.config/nvim
```

Then, install [`lazy.nvim`](https://github.com/folke/lazy.nvim) as instructed.
